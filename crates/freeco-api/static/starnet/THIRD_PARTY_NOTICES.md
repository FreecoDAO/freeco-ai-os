# Third-party notice: StarNet sprites

The PNG files in this directory are unmodified pixel-art sprites from StarNet
(https://github.com/FreecoDAO/starnet, a fork of androoAGI/starnet), copied at
commit `fbddbf992f8e7082196f07c3024781fcf1c276fc`. Each file was renamed from
`frontend/assets/sprites/<character>/<pose>.png` to `<character>-<pose>.png`
and from `frontend/assets/furniture/<name>.png` to `furniture-<name>.png`.

Only generic characters and furniture were taken. No logos, brand marks or
characters resembling real people or trademarked figures are included. No
StarNet code is included: the renderer in `static/js/pages/starnet.js` is
FreEco's own, written in StarNet's visual style.
